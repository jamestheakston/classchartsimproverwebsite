CC Improver

Export Your Debug File

Follow these steps to generate the debug data needed for your GitHub issue.

1

Check Installation

Ensure the ClassCharts Improver extension is installed and active while on the ClassCharts website.

2

Open Command Menu

Trigger the command menu using your keyboard shortcut:

Cmd + D (Mac) Ctrl + D (Win)
3

Export and Attach

Click "Export File" in the menu, then attach the downloaded file to your GitHub issue. Important: Do not change the file name.
