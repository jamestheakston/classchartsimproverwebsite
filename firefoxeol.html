Support for Firefox has ended

Effective immediately, ClassCharts Improver will no longer be maintained or updated for the Firefox browser.

Why this change?

Maintaining an extension across two different browser engines has become a significant hurdle. Firefox and Chrome use different technical standards (Gecko vs. Chromium), which effectively doubles the development workload.

Double the Testing

Every single bug fix requires separate testing and debugging for Firefox-specific quirks.

Slower Updates

Managing two codebases slows down the release of new features for everyone.

To ensure ClassCharts Improver remains a high-quality tool, I have decided to focus 100% of my efforts on the Chromium version. This allows for faster updates and a more stable experience.
